# Log.ic: Pytest Log Viewer

Log.ic is a Flask-based web application designed to simplify the viewing and analysis of logs generated by Pytest. It provides a real-time, auto-refreshing table interface to explore and filter log entries by level, making it easier for developers and testers to understand the results of Pytest runs.

## Key Features

- **Real-time Log Viewing:** Table auto-refreshes every 3s — no manual refresh needed.
- **Structured Parsing:** Extracts `date`, `time`, `level`, and `message` from each log line.
- **Log Filtering:** Filter logs by level — ALL, INFO, DEBUG, ERROR — with live entry counts.
- **Search:** Keyword search with inline highlighting, preserved across auto-refreshes.
- **Live / Paused Indicator:** Shows connection status in the top bar.
- **Dark Theme UI:** Clean, responsive dark interface with color-coded level pills.
- **Docker Support:** Run with a single `docker compose up --build` command.

## Log File

The application reads from `logs/log_file.log`. This file is mounted as a volume from your host machine, so pytest can write to it continuously and the UI will reflect changes within 3 seconds.

Expected log line format:
```
2024-01-15 08:00:01 INFO  Application started successfully
2024-01-15 08:01:20 ERROR Failed to connect to upstream service
2024-01-15 08:02:01 DEBUG Scanning 1200 records for cleanup
```

## How to Use

### Option 1 — Docker Compose (Recommended)

1. Clone the repository:
   ```bash
   git clone https://github.com/itachi9604/Log.ic.git
   cd Log.ic
   ```

2. Run the app:
   ```bash
   docker compose up --build
   ```

3. Point pytest at the `logs/` directory:
   ```bash
   pytest -o "log_file=/path/to/Log.ic/logs/log_file.log"
   ```

4. Open your browser at **http://localhost:5555**

---

### Option 2 — Pull Docker Image

1. Create a directory for your logs, e.g. `pytest_logs`:
   ```bash
   mkdir ~/Documents/pytest_logs
   cd ~/Documents/pytest_logs
   ```

2. Pull and run the image:
   ```bash
   docker pull itachi9604/log.ic
   docker run -p 5555:5555 -v .:/app/logs itachi9604/log.ic
   ```

3. Run pytest pointing to the same directory:
   ```bash
   pytest -o "log_file=/Users/tony.stark/Documents/pytest_logs/log_file.log"
   ```

> **Make sure the `-v` path in your Docker command and the `-o` path in your pytest argument point to the same directory.**

---

### Option 3 — Run Locally (Without Docker)

#### Prerequisites
- Python 3.11+
- Flask

```bash
git clone https://github.com/itachi9604/Log.ic.git
cd Log.ic
pip install -r requirements.txt
python app.py
```

Open your browser at **http://localhost:5555**
